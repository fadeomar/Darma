# Darma Visual Assets

Phase 10 introduces an original visual family under `public/atlas/`:

- `knowledge-constellation.svg` — connected knowledge, tools, and decisions.
- `open-workbench.svg` — open-source building and practical learning.
- `career-path.svg` — branching role exploration.
- `workflow-loop.svg` — iterative product and delivery systems.
- `decision-map.svg` — comparison and structured choice.
- `pathfinder-compass.svg` — guided career discovery.

## Rules

- Assets are stored locally and do not hotlink third-party illustrations.
- They use Darma design tokens and remain legible in light and dark themes.
- SVG files must not contain scripts, embedded remote resources, or fonts.
- Decorative visuals use an empty alt value; meaningful illustrations receive descriptive alt text.
- Product logos remain subject to the separate Resource Library icon policy.
