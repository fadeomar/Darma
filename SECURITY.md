# Security Policy

Please do not open a public issue for a vulnerability that could expose user data, credentials, deployment secrets, administrative access, or a practical exploitation path.

Use GitHub's private security advisory form for this repository. Include:

- the affected route, component, or dependency;
- reproduction steps;
- the likely impact;
- a safe proof of concept when necessary;
- any mitigation you have already tested.

For ordinary broken links, inaccurate content, UI problems, or non-sensitive bugs, use the public issue forms instead.

Do not test vulnerabilities against other users, production data, or third-party services without authorization.
